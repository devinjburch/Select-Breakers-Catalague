Searched web for Square D QED-2 / Power-Style, QMB/QMJ, I-Line filler/extension/sub-feed/mounting hardware. se.com, productinfo.se.com and download.se.com mostly return Akamai 403 to curl; WebFetch succeeded for 4620CT9601 PDF once and for ~25 se.com FAQ pages (intermittent 403 rate limiting - sequential fetches worked better). Extracted full QMB/QMJ switch-unit tables (Table 4-7), CB-unit lug kits, VCEL lugs, Class R/T kits, interlock kits, TVSS; I-Line plug-on lug table (SL..), blank filler/extension table with internal part numbers (FA243887); QED-2 group-mount I-Line breaker table (frames, mounting heights, lug ranges) and layout limits. Legacy: confirmed 'Saflex' = old QMB panelboard name (FA118445); QM (31 in.) vs QW (38 in.) interiors, pre-1961/1961-1984 cut-offs, EX/LEX plug-on extension retrofits, obsolete QW1BL/QW3BL fillers. Not found: 2700CT1601 OEM interior tables (blocked), QED-2 IB 80043-055 (blocked), 0600DB1004 (blocked), orderable QED splice/through-bus/end-closure kits (ordered by FO number), QMB CB unit catalog numbers (current), 'QMQB' (no hits - probably not a real designation), I-Line breaker handle padlock attachments specific to HD/JD/LA (only PowerPact B LV426908 / HJPAF etc. in passing - not recorded). Mounting heights for Q-frame and M-frame in 2700CT1101 group-mount table are C due to text-extraction column ambiguity. Non-schema claim keys were folded into standard keys (lug->kit_contents, fuse/interlock->breaker_compat).
